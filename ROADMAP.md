# Project Roadmap

This document tracks shipped capabilities and future engineering milestones for `cmd-ast-deobfuscator`.

---

## Shipped Capabilities

- [x] **Core AST Architecture & Tokenizer** — Lexical scanner, pushdown automaton state machine, abstract syntax tree models, and base visitor pipeline.
- [x] **Delayed Variable Expansion (`!VAR!`) Engine** — Lexical tokenization, recursive descent AST parsing, caret escape handling, and multi-pass delayed evaluation.
- [x] **Substring Slicing Constant Folding Pass** — Compiler optimization pass (`src/transforms/`) featuring `SlicingFolderPass`, `ConstantFolderPass`, and `PassManager` for fixed-point resolution of `%VAR:~s,l%` expressions, negative indices, boundary clamping, omitted parameters, nested parameters, and contiguous slice coalescing.
- [x] **Nested Caret Escape Normalization** — AST transform pass (`src/transforms/caret_normalizer.py`) featuring `CaretNormalizerPass` and `normalize_carets` for multi-level escape sequence resolution (`^^^`), quoting boundary tracking, adjacent literal coalescing, and pipeline integration into `PassManager` and `ConstantFolderPass`.
- [x] **Real-World Sample Deobfuscation Benchmark & Evaluation Suite** — Quantitative evaluation harness (`src/benchmark/`) computing Shannon entropy deltas, AST node reduction, and lexical token density across 12 production-representative obfuscation patterns with 100% ground-truth payload recovery.
- [x] **FOR Loop Variable & Parameter Path Modifier Interpreter** — Tokenizer, AST nodes, and evaluation engine (`src/modifiers.py`, `src/transforms/param_resolver.py`) supporting parameter path modifiers (`~dp`, `~f`, `~nx`, `~s`, `~a`, `~t`, `~z`, `~$PATH:`), 8.3 short name conversion, and FOR loop block statements.
- [x] **Control Flow Graph (CFG) Construction & Dynamic Jump Table Resolver** — Basic block partitioning, cmd.exe label fallthrough semantics, edge classification, reachability analysis, McCabe cyclomatic complexity metric, symbolic dynamic jump resolution (`goto %VAR%`, `call !TARGET!`), pattern prefix matching, Control Flow Flattening (CFF) dispatcher identification, and multi-format exporters (Mermaid, DOT, ASCII, JSON).
- [x] **Dead Code Elimination (DCE) & Unreferenced SET Pruning Pass** — Compiler optimization pass (`src/transforms/dce.py`) featuring `DeadCodeEliminationPass`, `VariableLivenessAnalyzer`, and `DCEMetrics` for fixed-point elimination of unreferenced variable assignments, consecutive dead store overwrites, unreachable statements following unconditional terminators (`exit`, `goto`), redundant block collapsing, and configurable symbol preservation.
- [x] **Arithmetic Expression Folding (`set /a`) & AST Optimization Pass** — Compiler-grade arithmetic evaluation engine (`src/arithmetic/`, `src/transforms/arithmetic_folder.py`) featuring `CmdArithmeticEvaluator` and `ArithmeticFolderPass` supporting 32-bit signed two's complement integer math, cmd.exe arithmetic and bitwise operators (`*`, `/`, `%`, `+`, `-`, `<<`, `>>`, `&`, `^`, `|`, `~`, `!`), compound assignments (`+=`, `-=`, etc.), comma-separated sequencing, decimal/hex/octal literal formats, and zero-division fault protection.
- [x] **String Reversal & Transposition Deobfuscation Engine** — Dedicated domain package (`src/reversal/`, `src/transforms/reversal_folder.py`) featuring `StringReversalAutomaton`, `ReversalPatternDetector`, and `ReversalFolderPass` for resolving Somalifuscator-style `FOR /L` reverse loops (`for /l %i in (len,-1,0)`), `FOR IN` dictionary index transpositions (`for %a in (indices)`), pushdown stack GOTO loops, decreasing slice sequences, rail-fence transpositions, and pipeline integration into `PassManager` and `BatchDeobfuscator`.
- [x] **Quote Toggle Boundary & Nested Quote Normalization Engine** — Dedicated domain package (`src/quotes/`, `src/transforms/quote_normalizer.py`) featuring `QuoteToggleAutomaton`, `QuoteNormalizer`, and `QuoteNormalizerPass` for tracking cmd.exe quotation toggle boundaries, unmasking escaped quotes (`^"`), collapsing empty quote pairs (`""`), reducing multi-level consecutive quotes (`""""`, `""""""`), deobfuscating command target executable names (`"c"m"d"` -> `cmd`), canonicalizing command arguments with whitespace/metacharacter awareness, and normalizing enclosed variable assignments (`set "k=v"`).
- [x] **I/O Redirection & Stream Routing Engine** — Dedicated domain package (`src/redirection/`, `src/transforms/redirection_pass.py`) featuring `StreamRouter`, `RedirectEntry`, `RedirectPlan`, and `RedirectionPass` for simulating cmd.exe stream handle routing, handle duplication chains (`2>&1`, `1>&2`, `>&2`), handle closing (`2>&-`), source handle routing (0..9), device sink classification (`nul`, `con`, `prn`, `aux`, `com1`..`com9`, `lpt1`..`lpt9`), stealth suppression pattern detection, caret/quote destination unmasking, unparsed literal argument lifting, and parenthesized block redirection grammar separation.
- [x] **Invoke-DOSfuscation Concatenation Pattern Heuristic Engine** — Dedicated domain package (`src/dosfuscation/`, `src/transforms/dosfuscation_pass.py`) featuring `DosfuscationConcatenationDecoder`, `DosfuscationDetector`, and `DosfuscationPass` for unmasking environment variable fragment chains (`%a%%b%%c%`), eliminating interleaved empty/junk variables (`%junk%c%junk%m%junk%d`), normalizing scrambled parameter delimiters (`,`, `;`) outside quotes and variable slices, folding FOR token accumulator loops into constant assignments, unrolling dynamic CALL execution trampolines, and scoring Invoke-DOSfuscation levels 1 through 5.
- [x] **0xidiz3r & Batch Packer Signature Detection and Control Flow De-flattening Engine** — Dedicated domain packages (`src/packers/`, `src/cff/`, `src/transforms/deflat_pass.py`) featuring `PackerSignatureDetector`, `PackerUnpacker`, `CFFAnalyzer`, `CFFLinearizer`, and `DeflatPass` for identifying 0xidiz3r obfuscation patterns, extracting CertUtil base64/hex self-extracting payload stubs, unrolling multi-layer wrappers, detecting central dispatcher hubs, splicing state machines into linear execution sequences, structuring conditional branches into `IfNode` trees, eliminating intermediate state mutations and dead hub jumps, and providing memory zeroization.
- [x] **Intermediate Representation (IR) & Multi-Target Transpiler Engine (Python 3 & PowerShell)** — Dedicated domain packages (`src/ir/`, `src/ir/targets/`) featuring `ASTToIRBuilder`, `PythonEmitter`, `PowerShellEmitter`, and `BatchTranspiler` for converting cmd.exe AST trees into language-agnostic Intermediate Representation, lifting batch subroutines into callable functions, translating path modifiers (`%~dp0` -> `SCRIPT_DIR = Path(__file__).resolve().parent` / `$PSScriptRoot`), mapping batch built-ins to native standard library constructs, emitting clean PEP 8 Python 3 and idiomatic PowerShell (.ps1) code, and providing telemetry with memory zeroization.
- [x] **Interactive Terminal AST Inspector & Colored Diff Visualizer (TUI Debugger)** — Dedicated domain package (`src/tui/`) featuring `ColoredDiffRenderer`, `ColoredASTTreeRenderer`, and `ASTPipelineDebugger` for unified and side-by-side split column colored diffs with box-drawing borders and terminal width auto-adaptation, colorized AST hierarchies with indexed node IDs and property inspection, interactive and scripted step-by-step transform pass debugging (`step`, `next`, `run`, `diff`, `tree`, `env`, `passes`, `reset`), quantitative diff telemetry (`compute_metrics`), and memory zeroization.
- [x] **High-Throughput Directory Batch Scanner & Bulk Deobfuscation Pipeline** — Dedicated domain package (`src/scanner/`) featuring `DirectoryScanner`, `FileCollector`, and `ScannerWorker` for parallel directory tree traversal, thread-pool worker orchestration, recursive path traversal defenses, multi-encoding fallback ingestion (UTF-8 BOM, CP437, CP1252, CP949), in-place modification with automated `.bak` backups, output directory mirroring, Shannon entropy delta computation, throughput telemetry, and multi-format reporting (JSON, CSV, Markdown).
- [x] **AST-based Malware IOC Extractor & Threat Intelligence Pipeline** — Dedicated domain package (`src/ioc/`, `src/transforms/ioc_pass.py`) featuring `IOCExtractor`, `IOCTransformPass`, models, patterns, and multi-format exporters for extracting IPv4/IPv6, URLs, domains, PE/script drops, hashes, and LOLBins with MITRE ATT&CK mapping, defanging, memory zeroization, and multi-format reports (JSON, CSV, Markdown, STIX 2.1).
- [x] **High-Performance Native C/Rust FFI Bindings & Standalone Binary Distribution Pipeline (v0.19.0)** — Native Rust acceleration core (`rust/`), standard C ABI header (`include/cmd_deobfuscator.h`), and ctypes Python bridge (`src/ffi/`) featuring `CmdDeobfuscatorBridge`, zero-copy string scanning, fast-path caret stripping, delimiter folding, entropy shifts, memory zeroization (`cmd_ffi_zeroize`), and CLI automation (`--ffi-export-header`, `--ffi-test-roundtrip`).
- [x] **Formal cmd.exe EBNF Grammar Specification, Conformance Validator & Canonical Test Corpus (v0.20.0)** — Dedicated domain package (`src/ebnf/`) featuring 49 formal EBNF production rules across lexical, expansion, syntactic, and control-flow categories, `EBNFConformanceValidator` for structural AST verification and grammar coverage matrix calculation, 25-sample canonical test corpus (`CANONICAL_CORPUS`) achieving 100% grammar rule coverage, and CLI automation (`--ebnf-validate`, `--ebnf-report`, `--ebnf-audit-suite`, `--ebnf-json`, `--ebnf-md`).
- [x] **Multi-Stage Batch Packer Unpacking & Multi-Tier Heuristic Deobfuscation Engine (v0.21.0)** — Dedicated domain packages (`src/packers/`, `src/transforms/deflat_pass.py`) featuring `MultiStagePackerEngine`, `PackerHeuristicDetector`, and `PackerUnpacker` for recursive layer-by-layer extraction across nested packaging cascades, specialized decoders (CertUtil Base64/Hex, PowerShell EncodedCommand UTF-16LE, Deflate/GZip streams, Echo dropper staging assemblers, 0xidiz3r noise wrappers, Somalifuscator variable substitutions), cryptographic cycle and loop detection, DoS payload size limits, Shannon entropy reduction telemetry, full `LayerTransition` provenance tracking, memory zeroization, and CLI flags (`--packers-detect`, `--packers-unpack`, `--packers-layers`).
- [x] **Control Flow Flattening (CFF) Dispatcher Loop Unrolling & Switch-Case Structuring Engine (v0.22.0)** — Dedicated domain packages (`src/cff/`, `src/transforms/deflat_pass.py`) featuring `CFFLoopDetector`, `CFFDispatcherUnroller`, `CFFLinearizer`, and `CFFDecompiler` for calculating graph reachability and dominator trees, identifying back-edges and natural loops, unrolling bounded deterministic state cycles into straight-line AST sequences, reconstructing data-dependent loops into structured while/for loops without dispatcher bounce, pruning unreachable dead states, detecting fallthrough state mutations, enforcing DoS iteration and step limits, providing memory zeroization, and CLI flags (`--cff-unroll`, `--cff-max-unroll`, `--cff-structured`, `--cff-report`).
- [x] **Enterprise SIEM & Sigma Obfuscation Primitive Detection Engine (v0.23.0)** — Dedicated domain package (`src/sigma/`) featuring `ObfuscationPrimitiveDetector`, `SigmaRuleGenerator`, `SIEMTranspiler`, and `SigmaTransformPass` for identifying 13 command-line obfuscation primitives (caret masking, quote fragmentation, substring slicing, variable concatenation, delimiter scrambling, arithmetic encoding, reversal loops, dynamic call trampolines, I/O stealth nulling, and script dropper stubs), computing quantitative risk scores with Shannon entropy weighting, generating compliant Sigma v2.0 YAML rules, transpiling detection logic into enterprise SIEM dialects (Splunk SPL, Elasticsearch EQL, Microsoft Sentinel KQL, IBM QRadar AQL, and JSON), providing memory zeroization, and CLI flags (`--sigma-detect`, `--sigma-generate`, `--sigma-target`, `--sigma-score`, `--sigma-out`).
